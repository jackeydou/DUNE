# swarmeval

Launch LLM agent swarms in controlled environments and record their trajectories for safety
analysis: collective deception, result hacking, covert communication.

Status: skeleton only. The only command so far is `swarm --version`. The design is in
[spec/2026-09-27-swarmeval-v1/](spec/2026-09-27-swarmeval-v1/README.md); setup and tasks are in
[docs/development.md](docs/development.md).
